# Maturity Levels

Use this to decide how far a scenario should be developed.

## Level 1: Blueprint

- docs only
- scenario summary
- suggested state machine
- suggested file split
- test focus

Best when proving breadth across many domains.

## Level 2: Discoverable Page

- example app route
- scenario cards or walkthrough
- links to docs and skill
- source registration for the page

Best when the team needs a visible pattern catalog but not full interactivity yet.

## Level 3: Full Interactive Example

- full `contexts / business / handlers / actions / hooks / views` split
- explicit state machine if async
- integration tests
- docs + source links + route discovery

Best when the scenario is a canonical teaching example or a likely template for real product work.
