# 공식 참조

원안 확인일: 2026-09-30. 저장소 통합일: 2026-10-01. 아래 자료는 플랫폼/라이브러리 의미를 확인하기 위한 1차 자료다. 이 프로젝트의 디렉터리·권한 분리·이벤트 명명·기본 수명 정책까지 외부 표준이 의무화한다는 뜻은 아니다.

## R0
WHATWG HTML — Custom elements, constructors/reactions, lifecycle, state-preserving moves.
https://html.spec.whatwg.org/multipage/custom-elements.html

## R1
Preact — preact-custom-element: 기존 페이지 일부 렌더링과 Custom Element wrapping.
https://preactjs.com/guide/v10/preact-custom-element/

## R2
Preact — Signals: .value 소비, computed, effect cleanup, JSX binding.
https://preactjs.com/guide/v10/signals/

최신 가이드와도 핵심 의미를 대조했지만 그 사실을 프로젝트 버전 업그레이드로 취급하지 않는다.
https://preactjs.com/guide/v11/signals/

## R3
WHATWG HTML — Boolean attributes / enumerated attributes.
https://html.spec.whatwg.org/multipage/common-microsyntaxes.html#boolean-attributes

## R4
Google web.dev — Custom Element Best Practices: rich properties, reflection, pre-upgrade properties, programmatic input event echo, host 설정.
https://web.dev/articles/custom-elements-best-practices

이 문서는 작성 권고이며 모든 항목을 예외 없는 플랫폼 의무로 확대하지 않는다.

## R5
WHATWG DOM — Event/CustomEvent, bubbles/composed/cancelable, dispatch 반환값.
https://dom.spec.whatwg.org/#interface-event
https://dom.spec.whatwg.org/#interface-customevent
https://dom.spec.whatwg.org/#concept-event-dispatch

## R6
WHATWG HTML — slot.
https://html.spec.whatwg.org/multipage/scripting.html#the-slot-element

## R7
CSSWG — CSS Shadow Module Level 1: shadow tree/slot 및 part 기반 스타일 노출.
https://drafts.csswg.org/css-shadow-1/

Working Draft 전체를 모든 브라우저에 구현된 기능 목록으로 취급하지 않는다. 이 보강안은 사용 기능에 대한 실제 browser 검증을 별도로 요구한다.

## R8
W3C WAI — ARIA Authoring Practices, Read Me First.
https://www.w3.org/WAI/ARIA/apg/practices/read-me-first/

## R9
TypeScript — Object Types, readonly Properties.
https://www.typescriptlang.org/docs/handbook/2/objects.html#readonly-properties

## R10
Preact — API Reference: render 및 component lifecycle.
https://preactjs.com/guide/v10/api-reference/
