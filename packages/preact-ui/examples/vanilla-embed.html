Context-Action Preact 순수 HTML 이식 실증

빌드 도구, Node.js, 리액트 설치 없이 브라우저에서 단일 UMD 스크립트만 로드하여 동작하는 두 가지 이식 방식입니다.

1. UMD Script 마운트 (Host JavaScript 제어 방식)

기존 CMS나 레거시 서버 렌더링 HTML의 빈 컨테이너에 mountOrderWorkspace()로 마운트합니다.

2. Web Component (Custom Element) 선언적 사용

일반 HTML 태그 <order-workspace>로 마크업에 직접 선언하며, 외부 자바스크립트는 표준 DOM Property/Event로 통신합니다.

3. 독립 모듈형 Web Components & Preact Signal 공유 실시간 동기화

서로 다른 DOM 계층(예: 상단 내비게이션 바와 본문 패널)에 위치한 <cart-badge>와 <cart-drawer>가 동일한 순수 Domain Signal을 공유하여 VDOM 충돌 없이 0ms로 실시간 동기화됩니다.

4. Form-Associated Custom Element (FACE) & 표준 HTML 폼 연동

<quantity-stepper>는 웹 표준 ElementInternals를 탑재하여, 별도의 JS 직렬화 코드 없이 일반 <form>의 FormData 자동 수집, 브라우저 기본 유효성 검사, 폼 리셋(form.reset())과 100% 네이티브로 연동됩니다.
