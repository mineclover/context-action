이 playground에서 확인하는 것

  1. 요청한 상태: setFormValue('demo-value')와 필수값 오류 상태를 요청합니다.
  2. fallback 상태: 네이티브 쓰기가 실패해도 컴포넌트 내부 폼 값은 유지됩니다.
  3. 네이티브 상태: 기본 시나리오에서는 쓰기가 거부되어 native 상태가 바뀌지 않으며, 아래 토글로 거부 여부를 바꿔 비교할 수 있습니다.
  4. 진단 결과: form-internals-error 이벤트로 실패한 작업 이름을 수집합니다.
