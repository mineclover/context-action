FACE 예외 처리 관찰하기

이 화면은 네이티브 ElementInternals 쓰기가 거부될 때 컴포넌트가 fallback 값을 유지하는지, 그리고 거부된 작업을 진단 이벤트로 확인할 수 있는지를 보여줍니다.

이 playground에서 확인하는 것

  1. 요청한 상태: setFormValue('demo-value')와 필수값 오류 상태를 요청합니다.
  2. fallback 상태: 네이티브 쓰기가 실패해도 컴포넌트 내부 폼 값은 유지됩니다.
  3. 네이티브 상태: 가짜 ElementInternals가 쓰기를 거부하므로 네이티브 유효성은 바뀌지 않습니다.
  4. 진단 결과: form-internals-error 이벤트로 실패한 작업 이름을 수집합니다.
