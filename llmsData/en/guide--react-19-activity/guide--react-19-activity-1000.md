React 19.2 Activity

React 19.2 Activity <Activity> is a React 19.2 component for keeping a part of the UI mounted while it is not visible. It preserves component, DOM, Store, and Action Provider state across a hide/reveal cycle without keeping that UI's effects and external subscriptions active. @context-action/react 3.0 requires React 19.2 or later.
