
# 범용 작업 할당 문서 생성 프롬프트

## 🎯 목적
지정된 대상(파일, 문서, 모듈, 태스크 등)에 대해 체계적인 작업 할당 및 진행상황 추적을 위한 관리 문서를 자동 생성합니다. 병렬 작업 수행, 순차 작업 진행, 의존성 관리 등 다양한 작업 방식을 지원합니다.

## 📌 핵심 기능

### 스캔 모드
- **파일 시스템 스캔**: 디렉토리 구조 기반 작업 목록 생성
- **문서 목록 스캔**: 마크다운, 텍스트 문서 기반 작업 생성
- **모듈/패키지 스캔**: 프로젝트 구조 기반 작업 관리
- **커스텀 목록**: 사용자 정의 항목 리스트 기반 작업 생성

### 작업 방식
- **병렬 작업**: 모든 항목에 동일한 작업 동시 수행
- **순차 작업**: 의존성에 따른 순서대로 작업 진행
- **그룹 작업**: 카테고리별 묶음 작업 관리
- **단계별 작업**: 페이즈별 진행 관리

## 📁 입력 정보

### 필수 매개변수
- **스캔 대상**: [대상 경로, 문서 목록, 또는 커스텀 항목]
- **출력 파일명**: [생성할 작업 할당 문서 이름]
- **작업 정의**: [수행할 작업 내용 및 목표]

### 선택적 매개변수
- **스캔 모드**: filesystem | documents | modules | custom (기본값: filesystem)
- **작업 방식**: parallel | sequential | grouped | phased (기본값: parallel)
- **제외 규칙**: [스캔에서 제외할 패턴 또는 항목]
- **포함 규칙**: [특정 패턴만 포함]
- **깊이 제한**: [스캔 깊이 또는 레벨 제한]
- **그룹화 기준**: [카테고리, 타입, 우선순위 등]
- **의존성 규칙**: [선행/후행 작업 관계 정의]
- **상태 옵션**: [커스텀 상태 정의 가능]
- **메타데이터**: [프로젝트명, 버전, 담당자 등]

## 📝 출력 규칙

### 1. 문서 헤더
```markdown
# 📋 [제목] 작업 관리 문서
- 생성일시: YYYY-MM-DD HH:MM
- 스캔 모드: [선택된 모드]
- 작업 방식: [선택된 방식]
- 총 항목: X개
- 진행 현황: 완료 Y개 | 진행중 Z개 | 대기 W개 | 보류 V개
---
```

### 2. 본문 형식

#### 기본 형식
```markdown
## 📂 [그룹/카테고리명]
- [ ] `항목명` - 상태
- [x] `항목명` - 상태 | 메타정보
- [-] `항목명` - 보류 (사유)
```

#### 상세 형식 (확장 정보 포함)
```markdown
## 📂 [그룹/카테고리명]
### 항목명
- **상태**: [ ] 대기 | [x] 완료 | [-] 보류
- **우선순위**: 높음 | 중간 | 낮음
- **예상 시간**: X시간
- **담당자**: @이름
- **의존성**: 선행작업, 관련항목
- **메모**: 추가 정보
```

### 3. 상태 표시 규칙

#### 체크박스 상태
- `[ ]` 대기/미시작
- `[x]` 완료
- `[-]` 보류/취소
- `[/]` 진행중 (선택적)
- `[?]` 검토필요 (선택적)

#### 작업 상태 태그
- `[TODO]` - 작업 예정
- `[IN_PROGRESS]` - 진행 중
- `[REVIEW]` - 검토 중
- `[DONE]` - 완료
- `[BLOCKED]` - 차단됨
- `[CANCELLED]` - 취소됨

#### 의존성 표시
- `→ 항목명` - 선행 작업
- `← 항목명` - 후행 작업
- `↔ 항목명` - 상호 의존
- `⊗ 항목명` - 차단 관계
