
# 작업 지시: 파일 구조 기반 작업 할당 문서 생성

## 🎯 목적
프로젝트 내 모든 파일에 대한 체계적인 작업 할당 및 진행상황 추적을 위한 관리 문서를 자동 생성합니다.

## 📌 요청사항
지정된 디렉토리의 모든 하위 파일과 폴더를 스캔하여, 
작업 할당 관리를 위한 마크다운(.md) 파일을 생성해주세요.

### 핵심 기능
- 파일 시스템 자동 스캔 및 문서화
- 작업 할당 상태 체크리스트 생성
- 진행상황 시각적 추적
- 담당자별 작업 현황 관리

## 📁 입력 정보

### 필수 매개변수
- **대상 경로**: [스캔할 루트 디렉토리 경로]
- **출력 파일명**: task_assignment.md

### 선택적 매개변수
- **제외 항목**: node_modules, .git, dist, build (기본값)
- **포함 확장자**: 전체 또는 특정 확장자 (예: `*.js,*.md`)
- **최대 깊이**: 디렉토리 스캔 깊이 제한 (기본값: 무제한)

## 📝 출력 규칙

### 1. 파일 헤더
```markdown
# 🗂️ [프로젝트명] 작업 할당 현황
- 생성일시: YYYY-MM-DD HH:MM
- 총 파일 수: X개
- 할당 완료: Y개 | 미할당: Z개 | 보류: W개
---
```

### 2. 본문 형식
각 디렉토리를 섹션으로 구분하고, 파일을 다음 형식으로 표시:

```markdown
## 📂 /디렉토리명
- [ ] `./경로/파일명.확장자` - 미할당
- [x] `./경로/파일명.확장자` - @담당자명 [상태]
- [-] `./경로/파일명.확장자` - 보류 (사유)
```

### 3. 상태 표시 규칙

#### 체크박스 상태
- `[ ]` 미할당 
- `[x]` 할당됨/작업중/완료
- `[-]` 보류/스킵

#### 작업 상태 
- [진행중] - 현재 작업 중
- [완료] - 작업 완료
- [검토중] - 리뷰 단계
- [대기중] - 할당됨, 시작 전

## 💾 예상 출력 (task_assignment.md)
