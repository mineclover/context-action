# LLM 리소스

이 섹션은 Context-Action 프레임워크와 LLM 통합을 위한 리소스와 문서를 포함합니다.

## 사용 가능한 리소스

### 컨벤션
- [컨벤션](./conventions.md) - LLM 통합을 위한 코딩 컨벤션 및 모범 사례

### 라이브러리 사양
- [라이브러리 사양](./library-specs.md) - 라이브러리 사용을 위한 기술 사양

### 생성된 파일
- **llms-500chars.txt** - 토큰 제한 컨텍스트를 위한 500자 요약
- **llms-minimal.txt** - 최소 필수 정보
- **llms-origin.txt** - 완전한 원본 문서

## 목적

이러한 리소스는 LLM이 Context-Action 프레임워크를 효과적으로 이해하고 작업할 수 있도록 도움을 주기 위해 설계되었으며, 다양한 컨텍스트 요구사항에 맞는 다양한 수준의 세부 정보를 제공하는 문서를 포함합니다.
